# Projeto Integrador EscamBOO — Plataforma de Economia Colaborativa para Troca de Serviços

## Introdução
Com o avanço das tecnologias digitais, o mundo tem passado por profundas transformações que modificaram significativamente as relações humanas e econômicas. Nesse cenário, a **economia colaborativa** surge como um modelo alternativo e eficaz, fundamentado no compartilhamento, na descentralização e no acesso a bens e serviços sem a obrigatoriedade de transações financeiras diretas. 

Embora o mercado conte com grandes plataformas de conexão, uma crise estrutural generalizada de inadimplência e vulnerabilidade financeira atinge milhões de cidadãos, limitando o poder de consumo e o acesso a serviços essenciais. 

O **EscamBOO** surge como resposta a essa problemática: uma plataforma digital voltada à mediação de trocas de serviços baseada na reciprocidade. O sistema permite que trabalhadores conectem suas habilidades às necessidades uns dos outros de forma justiça, promovendo inclusão social, redução de custos e uma alternativa econômica viável em tempos de crise.

## Tecnologias e Stacks Utilizadas

| Categoria | Tecnologia Adotada | Justificativa Técnica |
| :--- | :--- | :--- |
| **Linguagem Back-End** | PHP Nativo | Ampla maturidade no mercado, suporte ao paradigma de Orientação a Objetos, facilidade de integração nativa com o ecossistema web e aderência ao padrão arquitetural MVC. |
| **Linguagem Front-End** | JavaScript Nativo, HTML5 e CSS3 | Manipulação direta do DOM, conformidade com os padrões W3C e execução otimizada no lado do cliente (*client-side*). |
| **Framework Visual** | Bootstrap 5 | Padronização de componentes de interface, desenvolvimento ágil de folhas de estilo e responsividade nativa (*Mobile-First*). |
| **Banco de Dados** | SGBD MySQL (via phpMyAdmin) | Modelo relacional, persistência de dados robusta, integridade referencial e suporte nativo a consultas SQL complexas. |
| **IDE / Editores** | Visual Studio Code (VS Code) | Ambiente de desenvolvimento integrado com suporte nativo às linguagens utilizadas. |
| **Criptografia** | Bcrypt | Algoritmo de hash seguro para proteção e integridade das senhas dos usuários. |
| **Gestão do Projeto** | Trello & GitHub | Ferramentas de suporte para o quadro visual de tarefas e versionamento de código via Git. |
